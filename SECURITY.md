# Security Policy

## Supported versions

The project is in early development. Only the latest release receives
security fixes.

## Reporting a vulnerability

Please do not open a public issue.

Report privately through
[GitHub security advisories](../../security/advisories/new). Include what you
found, how to reproduce it, and the impact you expect.

You will get an acknowledgement, then updates as the fix progresses. Please
allow a fix to be released before disclosing publicly.

## Scope

In scope: the application, its plugin sandbox, the plugin permission system,
and first-party plugins. A plugin escaping its sandbox or acting beyond its
declared permissions is always a security issue.
